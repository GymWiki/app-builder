# Style options
- Rounded and soft: larger `AppRadius` values, `CardThemeData`, `FilledButton` with `StadiumBorder`.
- Minimal: no elevation (`elevation: 0`), outlined inputs, plenty of `AppSpacing.lg`.
- iPhone style: `CupertinoThemeData` via `MaterialBasedCupertinoThemeData`, `.adaptive` constructors (`Switch.adaptive`), `CupertinoPageTransitionsBuilder`.
- Material 3 default: do nothing extra.
